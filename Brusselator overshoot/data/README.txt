Compact results for the manuscript Supplement

manuscript_compact_results.zip contains the 18 unmodified files listed in
docs/MANUSCRIPT_DATA_MANIFEST.csv, plus that manifest. It reproduces the
processed inputs to the supplementary tables; it is not the full raw-trajectory
archive or every input required to rerun the numerical experiments.

From the repository root, restore with:
  python -m zipfile -e data/manuscript_compact_results.zip .
  python scripts/verify_repository.py
